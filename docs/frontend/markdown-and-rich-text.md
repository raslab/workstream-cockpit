# Markdown and rich text

Stream context and status update notes support formatted text where the UI exposes rich paste or markdown behavior.

Supported authoring should remain practical for operational notes:

- links
- lists
- inline code or code blocks where useful
- tables when pasted from rich sources
- plain text fallback

Formatting is presentation only. The durable content remains the stream context and narrative status/history note.

## Product guidance

Use formatting to make updates easier to scan, not to turn status updates into long reports. A normal status update should still be a concise 1-4 sentence progress/history note.
