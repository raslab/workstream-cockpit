# Product specs

Product specs define durable user-facing behavior and feature contracts for Workstream Cockpit.

## Concepts

- [Core concepts](./core-concepts.md) — streams, status updates, stream types, tags, views, and timeline.
- [Stream types](./stream-types.md) — primary stream classification; implemented as `Category` in the API/model.
- [Tags](./tags.md) — cross-cutting context labels and hashtag behavior.
- [Parent streams and sub-streams](./hierarchy-v1.md) — parent stream/sub-stream relationships, UI behavior, API/model changes, and implementation/test contract.
- [Views](./views.md) — saved cockpit angles for filters, grouping, sorting, and hierarchy scope.
- [Timeline](./timeline.md) — activity log, filters, structural events, and CSV export.
